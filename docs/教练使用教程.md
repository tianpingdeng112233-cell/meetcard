# MeetCard · 使用教程

力量举教练比赛日陪伴工具。两个屏:

- **桌面端 `/plan`** — 赛前规划。每把试举可以备 low/mid/hi 三档,Notes 写战术,自动算 warmup
- **手机端 `/live`** — 比赛日现场。实时看反超数学(同级 kg / 跨级 IPF GL),记录每把 ✓/✗

只有教练用,运动员不上手。

---

## 一次性准备

赛前在家或办公室做完,**比赛日不需要网络**。

1. **挂 VPN**(国内访问 Cloudflare Pages 需要,只第一次)
2. **桌面浏览器**(Mac/PC,Chrome/Edge/Safari 都行)访问:
   ```
   https://meetcard.pages.dev
   ```
3. **iPhone Safari** 访问同一 URL → 底部分享按钮 → "添加到主屏幕" → 命名 `MeetCard`
4. **从 iPhone 主屏幕图标打开一次** — 这一步关键,让 Service Worker 把所有资源 + 字体缓存到本地。之后飞行模式都能跑
5. 桌面端浏览器右上角通常会出现 "安装应用" 按钮,装一下,Mac 上多个独立 app 窗口

## 日常工作流

### 赛前几天

1. **桌面 `/plan`**
   - 顶上 `+ 新建运动员` → 填基本信息(姓名 / 性别 / 出生年 / 体重 / 级别 / 装备)
   - 三个 lift(SQ / BN / DL)× 三把试举(A1 / A2 / A3)× 三档(low / mid / hi)+ Notes 列
   - **A1 必选 opener tier**(低 / 中 / 高 哪一档是真开把),这决定 warmup ramp
   - A2 / A3 默认 mid,比赛日临时调
   - 边填边自动保存,不用 Ctrl+S

2. **分享到手机**
   - /plan 顶上红色 `分享到手机` 按钮 → 弹二维码 + URL
   - iPhone Safari / PWA 扫码 / 点击 → 自动跳到 /live,数据已写入手机本地
   - **改了 plan 之后**:再点一次"分享",重新扫 / 点新 URL,数据覆盖

### 比赛日现场

1. **iPhone 从主屏图标打开** PWA(不需要联网)
2. /live 自动显示:
   - 你的运动员卡
   - 两个 demo 对手(同级 + 跨级)— ✕ 删掉换成真对手
3. **每把试举完**:
   - 点该把对应的 status 圆 → cycle 到 ✓(成功)或 ✗(失败)
   - 顶上 `已确认 X 把 / 9` 自动更新
4. **看反超数学**:
   - 每张对手卡显示 `已确认差` 和 `预设拉满差`
5. **临时调重量**:直接改 NumInput 数字 / 加 alt
6. **热身**:点黄色 `热身` 按钮 → /warmup → 做完点 `热身完成 ✓` → 回 /live 该 lift 按钮变绿 ✓

## /plan 操作详解

### 三档预设(low / mid / hi)

每把试举可以备 3 个重量。意思:

| 档位 | 含义 | 典型 RPE |
|------|------|----------|
| low | 保守 / 稳 | 7.5-8 |
| mid | 默认 / 中等 | 8 |
| hi | 激进 / 极限尝试 | 9-9.5 |

填得越完整,比赛日临时调档越灵活。

### opener tier

A1(开把)必须明确选其中一档为真开把(单选 radio),这个数字驱动 warmup ramp 的目标重量。
A2 / A3 不需要选 tier,默认用 mid 档,比赛日 coach 临时切档。

### Notes 列

每个 cell 旁可写一行备注。比如:
- `状态差时开`
- `如果 200 fail,A2 改 195`
- `握杆稍宽`

比赛日在 /live 看不到 notes,只是教练自己规划时记录。

### Warmup 表

每个 lift 段落右侧自动算 6 步 warmup ramp(基于 opener 重量),可手动覆盖某行的 reps / load / jump / rest。

### 自动保存

打字后 500ms 静默保存到浏览器 IndexedDB。**关闭浏览器 / 切运动员 / 关 tab 也不丢**(刚改完立即关也不丢)。

### 底部三档合计

页面最底部并排三格:**状态差 / 正常 / 状态好**。每格对 SQ / BN / DL 各取该档 best,三项相加,给出**总重 + IPF GL 分**(下面小字标 `SQ + BN + DL` 明细)。一眼看清三种临场状态下的总成绩区间,赛前跟运动员对预期时用。

## /live 操作详解

### 我的运动员卡

三个 lift 现在都是**竖直堆叠**展示(2026-05-10 起,SQ / BN 不再是「单值 + `▼` 切档」):

- **SQ / BN**:把 plan 里的 low / mid / hi 三档堆叠,每行各自 status 圆(固定 3 档,不能现场增删)
- **DL**:同样堆叠,但可现场点 `+` 加并行预估,**最多 5 档**(deadlift 收官变数大,留更多备选空间)
- 比赛日看现场状态选哪档,就点那一行的状态圆 → 该把 collapse 到选中档(见下「状态圆点击」)

### 对手卡

- **SQ / BN**:默认单值
- **DL**:默认 1 个 preset,coach 不确定对手开多少时点 `+` 加备选(最多 3 档)
- ✕ 按钮整张卡删除

### 状态圆点击

每次点击循环:`pending ◯` → `made ✓` → `missed ✗` → `pending ◯`

**重要**:堆叠模式下(现在 SQ / BN / DL 都是),某行点 `✓` 或 `✗` 会**自动 collapse 其他档**(力量举规则:一把只有一个真实结果)。collapse 后该格左侧留一个**持久 `↶` 撤回按钮**,随时点它就恢复折叠前的整叠预设 —— 不再是旧版那种 10 秒就消失的 toast,点错了不用抢时间。(collapse 瞬间底部仍会闪一个即时撤销条,想立刻回退也行。)

### 热身按钮颜色

| 颜色 | 含义 |
|------|------|
| **黄色** `热身` | 还没做(默认) |
| **绿色** `热身 ✓` | 已在 /warmup 点过 `热身完成 ✓` |

### 顶上数字

- `试举进度 X / 9`:已 ✓ 或 ✗ 的把数(出 9 把就比赛结束)
- **试举进度块底部三档合计**(2026-05-10 加):`状态差 / 正常 / 状态好` 三格,跟桌面 `/plan` footer 同款语义,但会跟着比赛实时刷新 —— 各档按当前预设投射总重 + GL,missed 的把自动跳过,让教练随时看三种状态下的总成绩走向
- 卡片上 `已确认 X kg · GL Y`:只算 ✓ 成功的 best per-lift 和 + IPF GL 分
- 卡片上 `预设 X kg · GL Y`:每 lift 取所有非 ✗ 的最大 weight(main + alts),sum

## /warmup

进入这页只为做完热身确认。

- 显示 6 步 ramp(基于 opener 重量算)
- 每行 ▶ 启动倒计时(rest 时间)
- 修改某行的 reps / load / jump / rest 直接覆盖
- 顶上 `← 返回` 回 /live(状态保留)
- 底部 `热身完成 ✓` 按钮 → 回 /live + 该 lift 的热身按钮变绿

## 关键名词

### 已确认 / 预设

- **已确认 (kg / GL)**:已经举过且 ✓ **成功**的 best per-lift 之和。**事实**
- **预设 (kg / GL)**:每个 lift 取 main + alts 里非 ✗ 的最大值,sum 三个 lift。**理论上限**

### 已确认差 / 预设拉满差

- **已确认差** = 你的已确认 − 对手的已确认。**已经发生的差距**
- **预设拉满差** = 你的预设 − 对手的预设。**双方都按规划最高档成功的差距**
- 同级 → 单位 **kg**
- 跨级 → 单位 **GL**(IPF Goodlift Points,跨级公平对比)

> **正数 = 你领先**
> **负数 = 对手领先**

### IPF GL(Goodlift Points)

国际力量举联合会跨级对比公式,根据 体重 / 性别 / 装备(Raw 或 装备组)给一个换算分。
- GL 越高 = 相对越强
- 用于跨级别比较 — 例如 83kg 选手 vs 93kg 选手,直接比 kg 不公平,比 GL 才公平

## FAQ

### Q1: 国内访问慢 / 加载不出?
**A:** 第一次必须挂 VPN(教练大概率有,出国比赛看 IPF 视频用)。**装完 PWA 后比赛日不再需要 VPN**,所有资源走本地缓存。

### Q2: Mac 改完 plan,iPhone 看不到新数据?
**A:** 数据**不自动跨设备同步**。每次 Mac 改完点"分享到手机"扫 QR / 复制 URL,iPhone 打开新 URL 才会更新。这是设计取舍 — 不依赖云端、无账号、不联网也能用。

### Q3: 同一台设备的不同浏览器(Safari / Chrome)看到的数据不一样?
**A:** 每个浏览器 IndexedDB 是隔离的,需要在每个浏览器单独"分享 → 扫码"导入一次。一般教练只用一个 — iPhone 装 PWA 走 Safari,Mac 走 Chrome 即可。

### Q4: 误删了对手卡?
**A:** 没有撤销 —— 持久 `↶` 按钮只管堆叠 collapse 的恢复(SQ / BN / DL 某把点 ✓/✗ 后找回其他档),不覆盖整卡删除。重新点 `+ 加对手`,手动填入。

### Q5: 比赛日 PWA 启动失败 / 白屏?
**A:**
1. 检查 iPhone 是否飞行模式 — 即使飞行模式也应启动(资源全本地)
2. 主屏图标删了重装(回 Safari → 分享 → 添加到主屏幕)
3. 实在不行用 Safari 直接访问 https://meetcard.pages.dev (需要网络)

### Q6: 预设拉满差是负的,还能反超吗?
**A:** 还能,看几个变量:
- **对手 miss(✗)** — 他某把失败,该 lift 的 best 降级,total 跟着降
- **你超规划加重** — 比赛日临时把 NumInput 改高,把 ceiling 拉上去
- **跨级 GL 反超** — 跨级比 GL,你 weight class 更小可能 GL 占优
- **预设差越接近 0,越容易反超**

### Q7: 堆叠里选不同档,预设拉满差会变吗?
**A:** 只要还没 collapse(没在任何一行点 ✓/✗),整叠 low / mid / hi 都还在,max 集合不变,**预设拉满差不动**。

会改预设拉满差的操作:
- 标 ✗(missed)→ 该重量从 max 集合剔除
- 某行点 ✓/✗ 触发 collapse → 其他档被折叠出局(想找回点 `↶`)
- 改 NumInput 数字
- 加 / 删 alt(DL)

### Q8: PWA 怎么更新到最新版?
**A:** 每次启动 PWA 时 Service Worker 在后台检测新版本。
- 检测到新版会异步下载,**关掉 PWA 重启后**接管
- 想立即拿最新版:在 Safari 设置里清 meetcard.pages.dev 站点数据,重开 → 重装 PWA
- 比赛日尽量不要更新(避免引入未测的改动)
